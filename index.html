01

Fikamoja

Quick-commerce e-commerce web application · MERN Stack Developer

Live demo soon
  • Project goal — a Zepto-inspired quick-commerce platform where customers browse grocery and daily-essential categories, add items to a live cart and place orders through a fast express-delivery flow. Built end to end on the MERN stack.
  • Customer storefront in React.js — functional components and hooks (useState, useEffect, useContext, useMemo) with a reusable component set: ProductCard, CategoryTile, CartDrawer, SearchBar and OrderTracker.
  • Cart and session state with Redux — one store for cart items, quantities, user session and orders, kept consistent across page changes and reloads through normalised state and pure reducers.
  • REST APIs and database design — Node.js and Express endpoints for the catalog, category filtering, cart, order placement and order history in a clean MVC structure, backed by MongoDB and Mongoose schemas (Users, Products, Categories, Carts, Orders) with references and indexing.
  • Authentication and authorization — JWT login and registration, bcrypt password hashing, protected-route middleware, and role-based access control separating Customer from Admin.
  • Admin dashboard and live order tracking — manage products, categories and stock, and advance an order through Placed, Packed, Out for Delivery and Delivered.
  • Search, filtering and performance — debounced search and multi-filter browsing by category, price range and availability; lazy loading, React.lazy code splitting, memoisation and image optimisation on a mobile-first Tailwind UI.

Key learning

End-to-end ownership of a production-style e-commerce flow — API design, MongoDB data modelling, auth security and large-scale state management — and how frontend and backend contracts have to be designed together.

02

Autocount

Calculation & reporting system (ERP) · Frontend Developer

Internal product
  • What the system does — the frontend of a business ERP that handles a company's accounting and HR work in one place: invoices, revenue tracking, staff records and shift schedules. Built on React 19 and TypeScript with Vite, so pages open and respond in under a second.
  • Organised app data with Redux Toolkit — global state split into 40+ separate slices, one per module, which kept the data flow easy to follow and stopped values going out of sync between the accounting and HR screens.
  • Built long multi-step financial forms — Formik for multi-page invoice and accounting forms with Yup rules on every field, so totals, taxes and amounts recalculate instantly while typing and incorrect entries are blocked before saving.
  • Added role-based page protection — route guards that check the signed-in user's permissions before a page is allowed to open.
  • Dashboards and in-browser PDF reports — ApexCharts for revenue analytics graphs, FullCalendar for drag-and-drop staff rosters, and jsPDF for client-side invoice and report generation that downloads instantly.

Key learning

How to keep a large TypeScript codebase organised, how Redux Toolkit slices scale inside a real enterprise app, and how strong form validation protects financial data.

Car Selling Showroom

Role-based vehicle marketplace & management system

Live demo
